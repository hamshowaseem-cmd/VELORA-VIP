# VELORA-VIP

بوت تيليجرام عربي مستقل لتقديم معلومات وإرشادات عامة حول خدمات iChancy.

## التشغيل
- Python 3.10 أو أحدث
- تثبيت الاعتمادات: `pip install -r requirements.txt`
- تعيين متغير البيئة `TELEGRAM_BOT_TOKEN` إلى رمز البوت من BotFather
- تشغيل: `python bot.py`

## تنبيه
هذا البوت ليس ممثلاً رسمياً لـ iChancy ولا يتضمن حالياً ربطاً مع واجهة API رسمية أو تنفيذ عمليات شحن وسحب. لا تطلب من المستخدمين كلمات المرور أو رموز التحقق.
